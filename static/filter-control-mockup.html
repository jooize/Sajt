Filter control — variants

How a reader sets "how much do I want to see". All live; the label to the right echoes the current pick. Back to the timeline.

A — text row with the filter mark

What the timeline ships today: a macOS-style filter mark (three shrinking lines) naming the row, then plain words. ★ favorites is a fourth pick — it is a different axis (mine vs graded), but readers don't care about taxonomy.

B — text row, no icon

The words alone. Quieter; the pressed underline already says "filter". The icon in A buys a label for screen-magnifier users and costs one glyph of chrome.

C — hairline slider

The same 2px hairline as every row's quality meter, ticks at the same thresholds — the control and the data speak one language. The thumb snaps to everything / notable / best. ★ stays a separate toggle (favorites is not a point on the quality axis).

everything

D — segmented control

The macOS shape: a sliding thumb in a quiet capsule. Familiar and unmistakably a control — but it is the heaviest chrome on this page, on a site that owns almost none.

E — stepped bars

Strictness as a staircase: one bar shows everything, all three show only the best. Tiny, but it needs its label to be learnable — alone it reads as a signal-strength glyph.

everything

F — native range, undressed

For honesty: what the platform gives away free. Accessible out of the box, and it looks like a settings pane — which the timeline is not.
