Publish from a folder

Every entry on this site is a file — or a folder — sitting in one directory that syncs through iCloud Drive. The folder’s name is the address1: 1Clean names, native dates. The created date is read from the filesystem the first time the server sees the entry and remembered, so later syncs can’t lose it. No timestamp prefixes. tag open-source-licenses/ with public and esko.bar/open-source-licenses exists. Rename the folder and the address follows; the old one redirects.

The whole pipeline is the operating system. Finder and Files.app are the admin panel, tags are the taxonomy, and the creation date is the publication date. Nothing goes live by accident2 — 2Fail closed: anything without the public tag is invisible to the web, even if a sync client misbehaves. the server only serves what carries the public tag.

Note

An entry is live only while it carries the public tag. Remove the tag and the address answers 410 Gone — deliberately absent, not broken.

/// Only entries tagged `public` are served.
fn is_published(entry: &Entry) -> bool {
    entry.tags.iter().any(|tag| tag == "public")
}

If you can tag a file, you can publish. That is the entire interface.
